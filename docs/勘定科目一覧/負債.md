# 負債（Liabilities / 定位置: 貸方 `Credit`）

日商簿記3級の範囲における負債勘定の日英識別子対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| 日本語科目名 | 型・バリアント名 (`UpperCamelCase`) | 変数・メソッド名 (`snake_case`) | サブ区分・備考 |
| :--- | :--- | :--- | :--- |
| 支払手形 | `NotesPayable` | `notes_payable` | 流動負債（仕入債務） |
| 電子記録債務 | `ElectronicallyRecordedObligations` | `electronically_recorded_obligations` | 流動負債（仕入債務） |
| 買掛金 | `AccountsPayable` | `accounts_payable` | 流動負債（仕入債務） |
| 当座借越 | `BankOverdraft` | `bank_overdraft` | 流動負債（当座預金の貸方残高振替） |
| 借入金 | `LoansPayable` | `loans_payable` | 流動負債 / 固定負債（証書借入） |
| 手形借入金 | `LoansPayableOnNotes` | `loans_payable_on_notes` | 流動負債（手形による借入） |
| 未払金 | `AccountsPayableOther` | `accounts_payable_other` | 流動負債（商品以外の購入代金未払） |
| 前受金 | `AdvancesReceived` | `advances_received` | 流動負債（手付金・内金の受領） |
| 仮受金 | `SuspenseReceipts` | `suspense_receipts` | 流動負債（内容・金額未確定の入金） |
| 預り金 | `DepositsReceived` | `deposits_received` | 流動負債（一時的な預り金全般） |
| 従業員預り金 | `EmployeeDepositsReceived` | `employee_deposits_received` | 流動負債（従業員からの預り金） |
| 所得税預り金 | `IncomeTaxWithheld` | `income_tax_withheld` | 流動負債（源泉徴収所得税） |
| 社会保険料預り金 | `SocialInsurancePremiumsWithheld` | `social_insurance_premiums_withheld` | 流動負債（従業員負担分の社会保険料） |
| 未払配当金 | `DividendsPayable` | `dividends_payable` | 流動負債（株主総会決議後の未払配当） |
| 未払法人税等 | `IncomeTaxesPayable` | `income_taxes_payable` | 流動負債（確定した法人税等の未払分） |
| 仮受消費税 | `SuspenseConsumptionTaxReceived` | `suspense_consumption_tax_received` | 流動負債（税抜方式の売上等に係る消費税） |
| 未払消費税 | `ConsumptionTaxPayable` | `consumption_tax_payable` | 流動負債（決算時に確定した納付すべき消費税） |
| 未払費用 | `AccruedExpenses` | `accrued_expenses` | 流動負債（経過勘定・未払家賃/未払利息/未払給料等の表示科目） |
| 前受収益 | `UnearnedRevenues` | `unearned_revenues` | 流動負債（経過勘定・前受家賃/前受地代/前受利息等の表示科目） |
