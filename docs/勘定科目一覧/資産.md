# 資産（Assets / 定位置: 借方 `Debit`）

日商簿記3級の範囲における資産勘定の日英識別子対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| 日本語科目名     | 型・バリアント名 (`UpperCamelCase`)    | 変数・メソッド名 (`snake_case`)           | サブ区分・備考                                                 |
| :--------------- | :------------------------------------- | :---------------------------------------- | :------------------------------------------------------------- |
| 現金             | `Cash`                                 | `cash`                                    | 流動資産（現金・預金）                                         |
| 普通預金         | `OrdinaryDeposit`                      | `ordinary_deposit`                        | 流動資産（現金・預金）                                         |
| 定期預金         | `TimeDeposit`                          | `time_deposit`                            | 流動資産（現金・預金）                                         |
| 当座預金         | `CheckingAccount`                      | `checking_account`                        | 流動資産（現金・預金）                                         |
| 受取手形         | `NotesReceivable`                      | `notes_receivable`                        | 流動資産（売上債権）                                           |
| 電子記録債権     | `ElectronicallyRecordedMonetaryClaims` | `electronically_recorded_monetary_claims` | 流動資産（売上債権）                                           |
| 売掛金           | `AccountsReceivable`                   | `accounts_receivable`                     | 流動資産（売上債権）                                           |
| クレジット売掛金 | `CreditAccountsReceivable`             | `credit_accounts_receivable`              | 流動資産（売上債権）                                           |
| 商品             | `Merchandise`                          | `merchandise`                             | 流動資産（棚卸資産・繰越商品を含む）                           |
| 貯蔵品           | `Supplies`                             | `supplies`                                | 流動資産（未使用の切手・収入印紙・消耗品等）                   |
| 貸付金           | `LoansReceivable`                      | `loans_receivable`                        | 流動資産（その他の債権）                                       |
| 手形貸付金       | `LoansReceivableOnNotes`               | `loans_receivable_on_notes`               | 流動資産（その他の債権）                                       |
| 未収入金         | `AccountsReceivableOther`              | `accounts_receivable_other`               | 流動資産（商品以外の売却代金未収）                             |
| 前払金           | `AdvancePayments`                      | `advance_payments`                        | 流動資産（手付金・内金）                                       |
| 仮払金           | `SuspensePayments`                     | `suspense_payments`                       | 流動資産（内容・金額未確定の支出）                             |
| 立替金           | `AdvancesPaid`                         | `advances_paid`                           | 流動資産（取引先等に対する一時立替）                           |
| 従業員立替金     | `EmployeeAdvancesReceivable`           | `employee_advances_receivable`            | 流動資産（従業員に対する一時立替）                             |
| 受取商品券       | `GiftCertificatesReceived`             | `gift_certificates_received`              | 流動資産（他社発行の商品券）                                   |
| 仮払法人税等     | `PrepaidIncomeTaxes`                   | `prepaid_income_taxes`                    | 流動資産（中間納付等）                                         |
| 仮払消費税       | `SuspenseConsumptionTaxPaid`           | `suspense_consumption_tax_paid`           | 流動資産（税抜方式の仕入等に係る消費税）                       |
| 前払費用         | `PrepaidExpenses`                      | `prepaid_expenses`                        | 流動資産（経過勘定・前払家賃/前払保険料/前払利息等の表示科目） |
| 未収収益         | `AccruedRevenues`                      | `accrued_revenues`                        | 流動資産（経過勘定・未収利息/未収地代等の表示科目）            |
| 建物             | `Buildings`                            | `buildings`                               | 有形固定資産                                                   |
| 備品             | `Equipment`                            | `equipment`                               | 有形固定資産                                                   |
| 車両運搬具       | `Vehicles`                             | `vehicles`                                | 有形固定資産                                                   |
| 土地             | `Land`                                 | `land`                                    | 有形固定資産（非償却資産）                                     |
| 差入保証金       | `SecurityDeposits`                     | `security_deposits`                       | 投資その他の資産（敷金・保証金）                               |
