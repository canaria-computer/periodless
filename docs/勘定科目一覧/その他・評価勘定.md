# その他・評価勘定・決算および一時勘定（Valuation, Closing & Temporary Accounts）

日商簿記3級の範囲における評価勘定（資産の控除項目）、決算集合勘定、法人税等、および期中の一時勘定の日英識別子対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| 日本語科目名                         | 型・バリアント名 (`UpperCamelCase`) | 変数・メソッド名 (`snake_case`)   | サブ区分・備考                                                                                                                         |
| :----------------------------------- | :---------------------------------- | :-------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| 貸倒引当金                           | `AllowanceForDoubtfulAccounts`      | `allowance_for_doubtful_accounts` | 資産の評価勘定（定位置: 貸方 `Credit`、B/S上は受取手形・売掛金等から控除表示）                                                         |
| 減価償却累計額                       | `AccumulatedDepreciation`           | `accumulated_depreciation`        | 資産の評価勘定（定位置: 貸方 `Credit`、B/S上は建物・備品・車両運搬具から控除表示）                                                     |
| 損益                                 | `IncomeSummary`                     | `income_summary`                  | 決算集合勘定（決算振替仕訳で収益・費用を集約し、繰越利益剰余金へ振り替える勘定）                                                       |
| 法人税、住民税及び事業税（法人税等） | `IncomeTaxes`                       | `income_taxes`                    | 法人税等（定位置: 借方 `Debit`、税引前当期純利益から控除される費用性科目）                                                             |
| 現金過不足                           | `CashOverAndShort`                  | `cash_over_and_short`             | 期中一時勘定（現金の帳簿残高と実際有高の差額を処理する勘定。決算時に雑損 `MiscellaneousLoss` または雑益 `MiscellaneousIncome` へ振替） |
| 雑損                                 | `MiscellaneousLoss`                 | `miscellaneous_loss`              | 営業外費用（決算時に原因不明の現金不足額等を振り替える科目）                                                                           |
| 雑益                                 | `MiscellaneousIncome`               | `miscellaneous_income`            | 営業外収益（決算時に原因不明の現金過剰額等を振り替える科目）                                                                           |
