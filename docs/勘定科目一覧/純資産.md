# 純資産（Equity / Net Assets / 区分コード: `0011` / 定位置: 貸方 `Credit`）

> **注意**: 64bit
> 勘定科目ID（`0xC000_LLLL_BBBB_0000`）は設計途上の定義であり、今後変更される可能性があります。詳細は
> [`README.md`](README.md) および [`accounts.yaml`](accounts.yaml)
> を参照してください。

日商簿記3級の範囲における純資産（資本）勘定の日英識別子・64bit ID対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| 64bit ID (`u64`)        | 流動性 (`47..=32`) | 基底番号 (`31..=16`) | 日本語科目名   | 型・バリアント名 (`UpperCamelCase`) | 変数・メソッド名 (`snake_case`)     | サブ区分・備考                                               |
| :---------------------- | :----------------- | :------------------- | :------------- | :---------------------------------- | :---------------------------------- | :----------------------------------------------------------- |
| `0x3000_0000_0001_0000` | `0x0000`           | `0x0001`             | 資本金         | `CapitalStock`                      | `capital_stock`                     | 株主資本（出資を受けた資本金）                               |
| `0x3000_0000_0002_0000` | `0x0000`           | `0x0002`             | 資本準備金     | `CapitalReserve`                    | `capital_reserve`                   | 株主資本（資本剰余金・会社法上の準備金）                     |
| `0x3000_0000_0003_0000` | `0x0000`           | `0x0003`             | 繰越利益剰余金 | `RetainedEarningsBroughtForward`    | `retained_earnings_brought_forward` | 株主資本（利益剰余金・当期純損益の振替先および配当等の原資） |
