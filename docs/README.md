# Periodless

Periodless は、紙で行う仕訳をデジタル化する会計コアライブラリです。

## 目的と方針

- 紙の仕訳の記録を、そのままデジタルで扱えるようにします。それ以上の機能は目的に含めません。
- 初心者向けの補助や、簿記概念を隠すための内部処理は提供しません。利用者に経理のリテラシーを要求します。
- 簿記の概念を露出させ、利用者が最大限の制御を持てるようにします。会計上の効果は、すべて仕訳として現れます。
- 会計期間は、処理の単位としては持ちません。開始と終了で指定する集計の範囲です。一年という期間の規則を抽象化するものであり、会計ルールを破るものではありません。
- 画面、保存方式、実装言語は定めません。

## 準拠範囲

簿記三級の範囲を保証範囲とします。基準は、2022年4月1日施行の商工会議所簿記検定試験出題区分表と標準・許容勘定科目表に固定します。範囲外の記録は受け付けません。機能の拡張は、三級の範囲を完成させた後に行います。

## 記録の要求

### 仕訳

- 仕訳は直接記帳できます。伝票は必須ではありません。
- 一仕訳の借方合計と貸方合計は一致している必要があります。不一致の仕訳は、エラーとして拒否します。
- 下書きは存在しません。
- 現金の帳簿残高と実際有高の差額など、事実との差は、現金過不足などの勘定を使った貸借一致の仕訳で記帳します。固有の概念は設けません。

### 伝票

- 伝票は仕訳を発生させる記録です。
- 伝票から生成した仕訳は、生成元の伝票と生成根拠を相互に追跡できます。
- 伝票も記帳後は変更できません。取消や訂正は、訂正仕訳と訂正用伝票の追加で行います。

### 不変性と順序

- 記帳済みの仕訳と伝票は、変更も削除もできません。
- ライブラリは時計を持たず、日時は入力として与えられます。
- 最後に受け付けた仕訳より前の日時の仕訳は拒否します。取消仕訳、訂正仕訳、伝票由来の仕訳、自動生成の仕訳にも適用します。
- 同一日時の仕訳は受け入れ、順序は到達順序で定めます。相殺する記録が同時に到着しても、矛盾とは扱いません。

### 開始残高

- 会社設立のように、残高なしで帳簿を開始できます。
- 途中から導入する場合は、開始残高を貸借一致の一仕訳として記帳します。開始残高の仕訳は、帳簿開始時だけに置きます。

## 集計の要求

### 基本

財務諸表の取得、月次や日次の集計、決算は、いずれも記帳済みの仕訳に対するビューです。取得操作は帳簿を変更しません。

### 初期の必須出力

- 仕訳帳
- 損益計算書
- 貸借対照表

その他の帳簿は独立した機能にしません。必要であれば、仕訳に対するビューとして表現します。

### 任意期間の財務諸表

- 損益計算書は、指定した期間の収益と費用を対象にします。
- 貸借対照表は、指定した基準日時の残高を表します。期間開始前から引き継がれる残高も含みます。
- 決算振替の有無にかかわらず、任意の期間で損益計算書を取得できます。
- 集計の上限は、日時に加えて、到達順序上の位置でも指定できます。これにより、整理仕訳の前後で集計を区切れます。

### 決算

- 決算整理仕訳は、通常の仕訳として記帳します。その影響は、他の集計にも及びます。
- 経過期間や消費量が入力として与えられた場合に限り、利息や繰越商品などの整理仕訳を作成できます。入力のない整理は推測しません。
- 決算振替は特別な処理としません。期間損益と累積した利益の関係は、明示した集計規則として扱います。
- 実際の決算振替仕訳を記帳する場合も、任意期間の損益を取得できなくならないようにします。
- 繰越などの機械的な処理は自動化します。規則は、利用者が確認できる形で定義します。
- 整理の前後で名称が変わる項目は、勘定の変更ではなく、財務諸表上の表示科目への対応として扱います。この対応は、整理の前後を問わず同一の規則とします。

## 要求としない事項

- 財務諸表の各金額から、根拠仕訳や生成元伝票まで遡る機能は、初期の必須要件に含めません。
- 仕訳帳以外の帳簿に固有の名称や機能を設けることは要求しません。
- 現金実査を、特別な記録や状態として扱いません。

## 受入条件の骨子

- 貸借が不一致の仕訳は、必ず拒否される。
- 記帳済みの仕訳と伝票は、変更も削除もできない。
- 最後の仕訳より前の日時を持つ仕訳は、必ず拒否される。同一日時の仕訳は受け入れられ、到達順序で順序づけられる。
- 同じ記帳内容に対して、同じ範囲を指定すれば、同じ財務諸表が得られる。
- 決算振替を行っても、その前の期間の損益計算書を取得できる。
- 整理仕訳が到着した位置を境に、整理前と整理後の財務諸表を取得できる。
- 伝票から生成した仕訳と、その元の伝票の対応を確認できる。
