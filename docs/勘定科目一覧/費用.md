# 費用（Expenses / 定位置: 借方 `Debit`）

日商簿記3級の範囲における費用勘定の日英識別子対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| :--- | :--- | :--- | :--- |
| 仕入 | `Purchases` | `purchases` | 売上原価（三分法における商品仕入、決算整理後のP/L表示科目は売上原価 `CostOfGoodsSold`） |
| 発送費 | `ShippingExpenses` | `shipping_expenses` | 販売費及び一般管理費 |
| 広告費 | `AdvertisingExpenses` | `advertising_expenses` | 販売費及び一般管理費 |
| 給料 | `SalariesExpenses` | `salaries_expenses` | 販売費及び一般管理費 |
| 法定福利費 | `StatutoryWelfareExpenses` | `statutory_welfare_expenses` | 販売費及び一般管理費（社会保険料の会社負担分） |
| 旅費交通費 | `TravelAndTransportationExpenses` | `travel_and_transportation_expenses` | 販売費及び一般管理費 |
| 通信費 | `CommunicationExpenses` | `communication_expenses` | 販売費及び一般管理費 |
| 消耗品費 | `SuppliesExpenses` | `supplies_expenses` | 販売費及び一般管理費 |
| 水道光熱費 | `UtilitiesExpenses` | `utilities_expenses` | 販売費及び一般管理費（※標準許容科目として必要時に対応） |
| 支払家賃 | `RentExpenses` | `rent_expenses` | 販売費及び一般管理費 |

| 租税公課 | `TaxesAndDues` | `taxes_and_dues` | 販売費及び一般管理費（印紙税・固定資産税・税込方式の消費税等） |

| 支払利息 | `InterestExpenses` | `interest_expenses` | 営業外費用 |
| 固定資産売却損 | `LossOnSaleOfFixedAssets` | `loss_on_sale_of_fixed_assets` | 特別損失 |
