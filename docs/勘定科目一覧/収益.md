# 収益（Revenues / 定位置: 貸方 `Credit`）

日商簿記3級の範囲における収益勘定の日英識別子対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| 日本語科目名   | 型・バリアント名 (`UpperCamelCase`)      | 変数・メソッド名 (`snake_case`)               | サブ区分・備考                                                              |
| :------------- | :--------------------------------------- | :-------------------------------------------- | :-------------------------------------------------------------------------- |
| 売上           | `Sales`                                  | `sales`                                       | 売上高（三分法における商品売上）                                            |
| 商品売買益     | `GainOnSalesOfMerchandise`               | `gain_on_sales_of_merchandise`                | 売上高（分記法等における商品販売益）                                        |
| 受取利息       | `InterestIncome`                         | `interest_income`                             | 営業外収益                                                                  |
| 受取地代       | `RentIncome`                             | `rent_income`                                 | 営業外収益                                                                  |
| 償却債権取立益 | `GainOnRecoveryOfWrittenOffReceivables`  | `gain_on_recovery_of_written_off_receivables` | 営業外収益（過年度に貸倒処理した債権の回収）                                |
| 貸倒引当金戻入 | `ReversalOfAllowanceForDoubtfulAccounts` | `reversal_of_allowance_for_doubtful_accounts` | 営業外収益 / 特別利益（差額補充法で引当金残高が要設定額を上回る場合の戻入） |
| 固定資産売却益 | `GainOnSaleOfFixedAssets`                | `gain_on_sale_of_fixed_assets`                | 特別利益                                                                    |
