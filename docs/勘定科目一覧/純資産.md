# 純資産（Equity / Net Assets / 定位置: 貸方 `Credit`）

日商簿記3級の範囲における純資産（資本）勘定の日英識別子対訳表です。
コード上で勘定科目を表す型・列挙子（`UpperCamelCase`）および変数・メソッド名（`snake_case`）には、必ず以下の識別子を使用してください。

| 日本語科目名 | 型・バリアント名 (`UpperCamelCase`) | 変数・メソッド名 (`snake_case`) | サブ区分・備考 |
| :--- | :--- | :--- | :--- |
| 資本金 | `CapitalStock` | `capital_stock` | 株主資本（出資を受けた資本金） |
| 資本準備金 | `CapitalReserve` | `capital_reserve` | 株主資本（資本剰余金・会社法上の準備金） |
| 繰越利益剰余金 | `RetainedEarningsBroughtForward` | `retained_earnings_brought_forward` | 株主資本（利益剰余金・当期純損益の振替先および配当等の原資） |
