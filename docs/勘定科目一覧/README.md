# 勘定科目ID（64bit整数型）仕様と一覧

> **注意（暫定仕様）**: 本ドキュメントおよび `accounts.yaml` に記載されている
> 64bit
> 勘定科目IDのビットレイアウト、流動性スコア、および基底勘定科目番号は**設計途上の定義であり、今後の設計・実装の進行に伴って変更される可能性があります**。

---

## 1. 64bit 勘定科目ID ビットレイアウト（`0xC000_LLLL_BBBB_0000`）

勘定科目IDは 64bit 符号なし整数（Rust の `u64`）として表現します。 LSB を
`bit 0`、MSB を `bit 63`
としたとき、16進数表記（`0xC000_LLLL_BBBB_0000`）で各フィールドが 4bit / 12bit /
16bit の境界に揃うように以下のビット配置とします。

```text
63  60 59          48 47                  32 31                  16 15                   0
+-----+--------------+----------------------+----------------------+----------------------+
| Cat |  Reserved 1  |   Liquidity Score    | Base Account Number  |      Reserved 2      |
| 4b  |     12b      |         16b          |         16b          |         16b          |
+-----+--------------+----------------------+----------------------+----------------------+
 0xC       0x000             0xLLLL                 0xBBBB                 0x0000
```

| ビット範囲    | 幅    | フィールド名                                 | 16進マスク              | 内容                                                         |
| :------------ | :---- | :------------------------------------------- | :---------------------- | :----------------------------------------------------------- |
| `bit 63..=60` | 4bit  | **勘定区分 (`Category`)**                    | `0xF000_0000_0000_0000` | 資産・負債・純資産・費用・収益・評価勘定科目の区分           |
| `bit 59..=48` | 12bit | **将来予約 (`Reserved 1`)**                  | `0x0FFF_0000_0000_0000` | 将来の予約済み領域（常に `0x000`）                           |
| `bit 47..=32` | 16bit | **流動性スコア (`Liquidity Score`)**         | `0x0000_FFFF_0000_0000` | 流動性配列法に基づく降順ソート用スコア（`0xFFFF`〜`0x0000`） |
| `bit 31..=16` | 16bit | **基底勘定科目番号 (`Base Account Number`)** | `0x0000_0000_FFFF_0000` | 同一区分内で基底勘定科目を一意に識別する番号（`0x0001`〜）   |
| `bit 15..=0`  | 16bit | **将来予約 (`Reserved 2`)**                  | `0x0000_0000_0000_FFFF` | 将来の補助科目等の拡張用予約領域（常に `0x0000`）            |

---

## 2. 上位4ビット：勘定区分（`bit 63..=60`）

| 2進コード | 16進値 | 区分名                             | 英語識別子  | 定位置          | 流動性スコアの有無        |
| :-------- | :----- | :--------------------------------- | :---------- | :-------------- | :------------------------ |
| `0001`    | `0x1`  | 資産                               | `Asset`     | 借方 (`Debit`)  | あり (`0xFFFF`〜`0x0001`) |
| `0010`    | `0x2`  | 負債                               | `Liability` | 貸方 (`Credit`) | あり (`0xFFFF`〜`0x0001`) |
| `0011`    | `0x3`  | 純資産                             | `Equity`    | 貸方 (`Credit`) | なし (`0x0000`)           |
| `0100`    | `0x4`  | 費用                               | `Expense`   | 借方 (`Debit`)  | なし (`0x0000`)           |
| `0101`    | `0x5`  | 収益                               | `Revenue`   | 貸方 (`Credit`) | なし (`0x0000`)           |
| `0110`    | `0x6`  | 評価勘定科目（控除科目・特殊勘定） | `Valuation` | 科目による      | なし (`0x0000`)           |

## 3. 16bit 空間：流動性スコア（`bit 47..=32`）

貸借対照表（B/S）等における**流動性配列法**に従い、流動性スコアを**降順ソート**した際に流動性の高い科目が先頭に来るように割り当てます。

- **`0xFFFF`**: 最大超流動性（現金 `Cash`）
- **`0x0001`**: 無形固定資産（流動性を持つ科目の最小流動性基準値）
- **`0x0000`**: 該当なし（流動性概念を持たない純資産・費用・収益・評価勘定科目）

### 流動性スコア帯の目安

- **資産 (`0001`)**:
  - `0xFFFF` 〜 `0xFD00`: 現金・預金（現金 `0xFFFF`、当座預金 `0xFF00`、普通預金
    `0xFE00`、定期預金 `0xFD00`）
  - `0xE000` 〜 `0xDD00`:
    売上債権（受取手形、電子記録債権、売掛金、クレジット売掛金）
  - `0xC000` 〜 `0xBF00`: 棚卸資産（商品、貯蔵品）
  - `0xA000` 〜 `0x9500`:
    その他の流動資産（貸付金、手形貸付金、未収入金、前払金、仮払金、立替金、従業員立替金、受取商品券、仮払法人税等、仮払消費税、前払費用、未収収益）
  - `0x4000` 〜 `0x3D00`: 有形固定資産（建物、備品、車両運搬具、土地）
  - `0x2000`: 投資その他の資産（差入保証金）
  - `0x0001`: 無形固定資産（最小流動性アンカー）
- **負債 (`0010`)**:
  - `0xF000` 〜 `0xEE00`: 仕入債務（支払手形、電子記録債務、買掛金）
  - `0xD000` 〜 `0xCE00`: 短期借入金・当座借越（当座借越、借入金、手形借入金）
  - `0xB000` 〜 `0xA400`:
    その他の流動負債（未払金、前受金、仮受金、預り金、従業員預り金、所得税預り金、社会保険料預り金、未払配当金、未払法人税等、仮受消費税、未払消費税、未払費用、前受収益）
- **純資産 (`0011`) / 費用 (`0100`) / 収益 (`0101`) / 評価勘定科目 (`0110`)**:
  - すべて `0x0000`（該当なし）
