# Proposal

## Why

勘定科目（特に評価勘定科目を含む全勘定科目）をドメインコアや永続化層で一意かつ意味論的に扱えるよう、64bit整数型（`u64`）による勘定科目IDのビットレイアウト仕様（上位4bitの勘定区分、16bit空間の流動性スコア、bit
31..=16の基底勘定科目番号、および将来予約ビット）を策定し、YAML等の構造化ドキュメントとして定義する必要がある。

## What Changes

- 64bit整数型（`u64`）による勘定科目ID（`AccountId`）のビットレイアウト仕様を定義する（設計途中のため将来変更される可能性を明記する）：
  - **bit 63..=60（4bit / `<< 60`）**: 勘定区分（Category）
    - `0001` (`0x1`): 資産 (`Asset`)
    - `0010` (`0x2`): 負債 (`Liability`)
    - `0011` (`0x3`): 純資産 (`Equity`)
    - `0100` (`0x4`): 費用 (`Expense`)
    - `0101` (`0x5`): 収益 (`Revenue`)
    - `0110` (`0x6`): 評価勘定科目・特殊勘定 (`Valuation / Special`)
  - **bit 59..=48（12bit / `<< 48`）**: 将来予約（Reserved 1、`0x000`）
  - **bit 47..=32（16bit / `<< 32`）**: 流動性スコア（Liquidity
    Score、流動性配列法に基づく降順ソート用スコア）
    - `0xFFFF`: 最大超流動性（現金など）
    - `0x0001`: 無形固定資産（最小流動性）
    - `0x0000`:
      該当なし（流動性概念を持たない純資産・費用・収益・評価勘定科目など）
  - **bit 31..=16（16bit / `<< 16`）**: 基底勘定科目番号（Base Account
    Number、同一区分・同一流動性内でも基底勘定科目を一意に識別する番号）
  - **bit 15..=0（16bit / `<< 0`）**: 将来予約（Reserved
    2、補助科目等の将来拡張用に予約、`0x0000`）
- `docs/勘定科目一覧/` における勘定科目の区分整理と64bit
  ID定義（YAML形式および一覧ドキュメント）を追加・更新する：
  - `評価勘定科目（0110）`
    として「貸倒引当金」「減価償却累計額」「現金過不足」「損益」を定義し、流動性スコアを
    `0x0000`（該当なし）とする。
  - 既存の `その他・評価勘定.md`
    に含まれていた「法人税、住民税及び事業税（法人税等）」「雑損」を
    `費用（0100）`、「雑益」を `収益（0101）` の区分として整理する。
  - 全勘定科目の64bit ID（16進表記
    `0xC000_LLLL_BBBB_0000`）、勘定区分コード、流動性スコア、基底勘定科目番号、日英識別子をまとめた
    YAML ドキュメント（`docs/勘定科目一覧/accounts.yaml`
    等）および解説ドキュメントを作成する。

## Capabilities

### New Capabilities

- `account-id-encoding`: 64bit整数型による勘定科目IDのビットレイアウト仕様（bit
  63..=60の勘定区分、bit 47..=32の流動性スコア、bit
  31..=16の基底勘定科目番号、予約ビット）とYAML形式でのID定義体系

### Modified Capabilities

- `account-terminology`: `docs/勘定科目一覧/`
  における評価勘定科目（`0110`）の分類整理（法人税等・雑損益の費用/収益への統合を含む）と64bit勘定科目ID・YAML定義の追加

## Impact

- 新規・更新ドキュメント:
  - `docs/勘定科目一覧/accounts.yaml`（全勘定科目の64bit
    ID・ビット内訳・日英識別子のYAML定義）
  - `docs/勘定科目一覧/README.md`（64bit勘定科目IDのビットレイアウト仕様と流動性スコア割り当て方針の解説、および設計途上である旨の注記）
  - `docs/勘定科目一覧/*.md`（区分整理およびID列の反映、不要となった一時メモ
    `評価勘定科目.txt` の統合整理）
  - `AGENTS.md`, `CONTRIBUTING.md`（必要に応じた参照パスの更新）
